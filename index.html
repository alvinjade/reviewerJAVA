01

Introduction to Java

🧠 High-Level & Object-Oriented

Madaling basahin ng tao at naka-organisa gamit ang Classes at Objects.

🌍 WORA (Platform Independent)

Write Once, Run Anywhere. Gumagana sa kahit anong OS basta may Java Virtual Machine (JVM).

Basic Program Structure Main.java 
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

🔹 public class Main: Pangalan ng klase. Dapat kapareho ito ng file name na Main.java.

🔹 main(): Ang entry point o simula ng pagtakbo ng Java program.

🔹 System.out.println(): Nagpi-print ng text sa screen at lumilipat sa kasunod na linya.

02

Naming Rules & Code Style

  • Case-Sensitive Magkaiba ang age at Age.
  • Class Names (UpperCamelCase) Nagsisimula sa malaking titik ang bawat salita. Hal: StudentProfile.
  • Variables & Methods (lowerCamelCase) Nagsisimula sa maliit na titik ang unang salita. Hal: studentName, calculateAverage().
03

Input, Process, & Output (Scanner)

System.out.print() Nagpi-print PERO hindi lumilipat sa bagong linya.
System.out.println() Nagpi-print at AGAD LUMILIPAT sa bagong linya.
Scanner Example Code 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter name: ");
        String name = input.nextLine(); // Bumabasa ng buong linya
        System.out.println("Hello " + name);
    }
}
04

Variables & Data Types

int int age = 20;

Buong numero (Whole numbers).

double double price = 99.95;

Numerong may decimal point.

char char grade = 'A';

Isang karakter lang (Gumagamit ng single quote '').

boolean boolean isPass = true;

Magiging true o false lang.

String (Reference Type) String name = "Maria";

Mga salita o text (Gumagamit ng double quote ""). Hindi ito primitive type.

Typecasting Basics
Implicit (Widening)

Awtomatiko mula sa maliit papuntang malaking type (int ➔ double).

double b = 10; // 10.0
Explicit (Narrowing)

Manwal na pag-convert gamit ang cast notation (Nawawala ang decimal!).

int p = (int) 99.95; // 99
05

Java Operators & Bitwise

⚠️ Tandaan sa Exam: Modulo (%) at Integer Division (/)

• Modulo (%): Kukuha ng tira (remainder). Hal: 13 % 6 = 1.
• Kapag int divided by int (/), tinitapon ang decimal! Hal: 7 / 2 = 3 (hindi 3.5).

Logical Operators
&& (AND) Dapat PAREHONG true
|| (OR) Kahit ISA lang ay true
! (NOT) Pina-baliktad ang boolean
String Concatenation Trap 
System.out.println("Result: " + 5 + 5);   // Output: Result: 55
System.out.println("Result: " + (5 + 5)); // Output: Result: 10
06

Decision Making (If & Switch)

Traditional Switch

Kailangan ng break; para hindi mag-fall-through o tumuloy sa susunod na case!

switch(day) {
    case "MON": 
        doWork(); 
        break;
}
Modern Switch Arrow (->)

Hindi nangangailangan ng break; at awtomatikong naiwasan ang fall-through.

switch(day) {
    case "MON" -> "Weekday";
};

for Loop

while Loop

do-while Loop
